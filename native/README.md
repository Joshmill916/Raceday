# RaceDay native apps (iPhone + Android)

This folder wraps the RaceDay web app (`raceday/index.html`) in a native shell using
[Capacitor](https://capacitorjs.com) 8. **The web app stays the single source.** Nothing here
is a second copy of the app; `npm run sync` copies `raceday/` into `www/` at build time.
For why, the trade-offs, and costs, see [`../NATIVE-APP.md`](../NATIVE-APP.md).

| Path | What it is |
|---|---|
| `capacitor.config.json` | App id `com.victoryraceday.raceday`, name, background color |
| `scripts/copy-web.mjs` | Copies `index.html`, icon, manifest from `raceday/` → `www/` (not `sw.js`) |
| `ios/` | Xcode project (generated by `cap add ios`, committed so settings persist) |
| `android/` | Android Studio project (generated by `cap add android`, committed) |
| `well-known/` | Templates for the deep-link files the website must serve (see below) |
| `www/`, `node_modules/` | Build output, gitignored |

## Build it

You need Node 20+. For iPhone you also need a **Mac with Xcode**. For Android you need
**Android Studio** (any OS).

```bash
cd native
npm install
npm run ios        # copy web app → sync → opens Xcode, then press ▶ to run on a phone/simulator
npm run android    # same, opens Android Studio
```

Run `npm run sync` after **every** change to `raceday/index.html`. The phone app only gets
changes when you rebuild and ship a store update. That's the big difference from the website.

## What's already handled in `raceday/index.html`

Everything is gated on `isNativeApp()`, which is true only inside the shell. The website is unchanged.
Guard: `tests/test-native-shell.js`.

- **Links and QR codes for other devices** (`appBaseUrl()`): staff station links, the spectator
  QR and the QR poster point at `https://victoryraceday.com/raceday/`, not the app's own
  `capacitor://localhost` address.
- **No service worker.** The files ship inside the app.
- **Usage analytics still send.** Without this, `devHost()` would read the app's "localhost"
  address as a dev copy and drop every row.
- **Deep links.** A `?sync=…&role=…` link opened from the camera or Messages reloads the
  page with that query once, and the existing `handleUrlParams()` applies it.
- **Site links** like `/?home=1` open the public website in the phone's browser.

## Turning on deep links (station links open the app)

1. **iOS:** in Xcode → App target → Signing & Capabilities → **+ Associated Domains** →
   `applinks:victoryraceday.com`. Put your Apple Team ID in
   `well-known/apple-app-site-association` (replace `TEAMID`).
2. **Android:** the intent filter is already in `android/app/src/main/AndroidManifest.xml`.
   Paste the SHA-256 fingerprint from Play Console → App integrity → App signing into
   `well-known/assetlinks.json`.
3. Publish both files at `https://victoryraceday.com/.well-known/`. GitHub Pages skips dot-folders
   unless the site has a `.nojekyll` file or a `_config.yml` `include: [".well-known"]`.
   Don't publish them until the real IDs are filled in.

## Still to do before store submission

See the phase plan in `../NATIVE-APP.md`. The must-fixes are:

- **Backup download / CSV export.** `<a download>` blob links don't save files in the iOS
  web view. Use `@capacitor/filesystem` + `@capacitor/share` when `isNativeApp()`.
- **Printing** (QR poster, lineup sheets). These use `window.open('')` + `document.write`, which
  opens nothing in the shell. Print from a hidden iframe, or use a print plugin.
- **License purchase buttons.** Hide the Stripe "Buy" links in the native build, or show
  them only on the US storefront. Code entry stays.
- **Firebase.** Test anonymous sign-in on a real iPhone. If the Firebase API key has HTTP-referrer
  restrictions, add the app's bundle id / origins.
- **App icons and splash screens.** Generate them with `npx @capacitor/assets generate` from a
  1024×1024 icon.
