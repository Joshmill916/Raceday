Getting started

What RaceDay is, and what it costs to try it.

Is there a free trial?
Yes — one full race day, every feature unlocked, no card and no account. Days only count when you actually sign drivers in, so setting things up and poking around doesn't burn it.
Do I need to install anything?
No — it runs in the browser on whatever you already have (phone, tablet, laptop). You can add it to your home screen for an app-like icon, but there's nothing to download from a store.
Do spectators or drivers ever pay?
No, never. Fans watch live lineups and results free — just a QR code, no app, no signup. A driver's Driven profile is free to build too; the only optional cost is Driven Pro, covered below.
Switching to the new version

RaceDay was rebuilt from the ground up. New tracks start on it automatically — here's what that means if you're already running the classic app.

I'm already using RaceDay — do I have to switch?
No. The classic version keeps working exactly as it always has, for as long as you want to keep using it. Nothing about your setup changes on its own.
If I want to move over, how do I bring my season with me?
Open the classic app → Admin, and you'll see a "new version available" notice with a Download backup button. Grab that file, open the new version, then in its Admin → Backup & export section use Restore from backup and pick the file. Your track, classes, roster, and history all come across.
Will that erase my data on the old version?
No — it's a copy, not a move. Your classic app keeps everything exactly as it was, so you can try the new version risk-free and keep racing on the old one until you're ready.
My license didn't carry over — is that a bug?
That's on purpose. A backup file never carries a license, so a device restoring someone else's backup can't inherit their paid access. Just re-enter your own access code in the new version's Admin → License and you're back to fully licensed.
Running a race night

Where the actual heat/B-main/feature settings live, versus where you run the night itself.

Where do I set up heat races and the feature?
That's a one-time setting, not something you touch every night: Admin → Race format (called "Format" in the classic app) is where heat size, B-main size, feature size, and transfer counts live. Set it once per class and it sticks.
How do I actually run heats and the feature on race night?
You don't set that up separately — use the Lineups and Results (classic) or Score (new version) tabs. The app walks you through Sign-up → Heats → B-mains → Features → Archive automatically as you enter finishes.
Can more than one device work the same race night?
Yes — a sign-up laptop, a scoring tablet, and a TV display can all stay in sync live. Admin → Multi-device sync has the join codes/QR for each role.
Driven (the driver app)

The companion app a driver's profile lives in, separate from the track's own app.

What does Driven cost?
Building a profile — name, car number, sponsors, photo, career stats, and now aliases, crew, and highlights — is free. The only paid tier is Pro ($3/mo or $30/yr), which unlocks the full broadcast-look card (photo, team color, checkered stripe) that tracks see. It's never required to sign up or race.
I upgraded to Pro but my card still looks basic — what's wrong?
Open Driven and let it fully load (it re-checks your subscription each time it opens), then have the track hit Refresh on your driver card in RaceDay — it only pulls your latest card on request, not automatically. Still stuck after that? Email us using the link at the bottom of this page.
How does a driver link their profile to a track?
They give the track their short link code at sign-up (or type it in directly on their Driven card's Link tab). The track pulls in the published card — no account needed on the track's side.
Data & backups

What happens if a device is lost, dropped, or replaced.

What happens if I lose my device or it breaks?
Download a backup regularly from Admin — it's one file with your whole season. Restoring it on a new device brings everything back except the license/PIN, which stay device-specific on purpose. Turning on cloud backup in Admin does this automatically in the background.
Can I run more than one track on the same device?
Yes — The Garage lets one device hold more than one track's data and switch between them, each keeping its own PIN, license, and season completely separate.
